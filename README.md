# Nazar Begen portfolio

A static website. No build step, API keys, or ChatGPT hosting required.

## GitHub Pages

1. Extract this ZIP.
2. Upload index.html, the assets folder and .nojekyll to the root of your GitHub repository.
3. Enable GitHub Pages for that branch and its root directory in repository settings.

Keep the assets folder next to index.html. Upload the extracted files, not the ZIP itself.

YouTube videos stay embedded from YouTube; viewing them requires internet access.
The Honi Poke website video and all artwork are included locally.

The Edit portfolio button saves changes in your browser. To publish edits, use Export website in the editor and replace index.html in the repository.
